Getting an API key

For Nalapakam's optional AI reading.

Nalapakam works without a key: recipes are read on your iPhone. A key from Anthropic, OpenAI or Google lets their models read long notes, photos and videos far better. You need only one. The key is yours: it is billed to your own account with that company, stays in your iPhone's Keychain, and is sent only to that company.

Which one? Gemini is the only one that can read a YouTube video or a video file itself, and it hears Indian languages best, so it is the most useful single key. Google offers a free tier with daily limits. Claude and GPT read text and photos very well and need a little prepaid credit.

A ChatGPT, Claude or Gemini chat subscription does not include API access; the key comes from each company's developer site.

Google Gemini

1. Go to aistudio.google.com/apikey and sign in with your Google account.

2. Choose Create API key. If you are asked for a project, let it create one.

3. Copy the key. It starts with AIza.

The free tier has daily limits and resets at midnight Pacific time. For more, add billing to the project in Google AI Studio. Google's terms apply to what you send.

Anthropic (Claude)

1. Go to console.anthropic.com and create an account.

2. Under Billing, add a small amount of credit; a few dollars lasts a long time, since a recipe costs a fraction of a cent.

3. Under API keys, choose Create key, name it Nalapakam, and copy it. It starts with sk-ant- and is shown only once.

OpenAI (GPT)

1. Go to platform.openai.com and sign in.

2. Under Billing, add a small amount of credit.

3. Under API keys, choose Create new secret key, name it Nalapakam, and copy it. It starts with sk- and is shown only once.

Adding it to Nalapakam

1. In Nalapakam, open Settings, then Anthropic API, OpenAI API or Google Gemini API under Reading recipes.

2. Paste the key and save. Nalapakam shows what it will send to that company and asks before saving.

3. With more than one key, Settings › Order sets which is tried first.

Keeping it safe

Treat a key like a password: do not share it or post it, including in a support issue. You can delete it at the company's site at any time, and remove it from Nalapakam in Settings. Spending limits in each company's billing settings cap what a key can cost.
